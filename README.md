# 🌸 Flower Garden Lab

## Objectives

This lab strengthens your understanding of:

- Classes and methods in Java
- Using an `ArrayList<String>`
- Storing structured data inside a `String`
- Extracting numeric values with `Integer.parseInt()`
- Writing methods that call other methods

Description

You will create a class named FlowerGarden that stores flower data inside an ArrayList<string>.

Each element in the ArrayList represents one flower type and contains two pieces of information:

A two-digit count (as text)

The flower name

Example Flower Strings

"14 daisy" → there are 14 daisies

"01 rose" → there is 1 rose

"00 poppy" → there are 0 poppies

You will need to use Integer.parseInt() to extract the numeric count from the front of the string.</string>
